# Contributing to HUDMind

Thank you for contributing! The `main` branch is **protected**, so all changes must go through a **Pull Request** passing CI (`native-dotnet9-tests` and `native-windows-build`).

## Key Guides Before You Start
1. **[Complete Pull Request Guide](docs/pull_request_guide.en.md)** — branch workflow, PR types (`feat`, `fix`, `bug`, `refactor`, `perf`, `security`, `docs`, `test`, `build`, `ci`, `chore`, `revert`), required PR contents, and local verification commands.
2. **[Release Versioning Nomenclature (`vN.N.N`)](docs/versioning_and_releases.en.md)** — SemVer rules (`MAJOR.MINOR.PATCH`) and pre-release policy.
3. **[Technical Architecture](docs/architecture.en.md)** and **[Test Plan & Report](docs/test_plan_ieee29119.en.md)**.
4. **[Security Policy](SECURITY.en.md)** — 100% passive anti-cheat safe guarantee and zero external NuGet dependencies.
5. **Bilingual Docs Rule:** any new or modified documentation file in `docs/` or repo root must keep both **`.es.md` and `.en.md`** versions with cross-links at the top.
