# Base de Conocimiento Táctico y Macro — Dota 2

## 1. Timings Críticos de Mapa y Reloj (Predictivo)
- **Runas de Poder (`cada 2:00` en río desde `6:00`) y Bounties (`cada 3:00`):** Avisar `15–20s` antes de la marca (`x:40`) para asegurar control o botella.
- **Runas de Sabiduría (`cada 7:00`):** Recordar `20s` antes para no regalar experiencia gratis.
- **Campamentos / Stack (`x:53–x:55`) y Pull (`x:15 / x:45`):** Guiar ventana exacta según reloj GSI/HUD antes de que pase el minuto.

## 2. Línea, Supervivencia y Recursos
- **Falta de Vision en Minimapa + `< 40% HP/Maná`:** Avisar **antes** del gank enemigo cuando el jugador está adelantado bajo torre contraria sin TP ni visión.
- **TP Scroll, Courier y BKB / Buyback:** Verificar tener siempre **TP Scroll** en inventario, mandar regeneración temprano sin caminar a base innecesariamente, y guardar oro para **Buyback** en minuto `35+`.

## 3. Objetivos (Tormentor / Roshan / Aegis)
- Preparar *Smoke of Deceit* y visión profunda antes de forzar Roshan (`20:00`+) o Tormentor; no pushear *high ground* sin Aegis o bajas confirmadas.

## 4. Lista Negra de UI (En modo `match`)
- Menú principal, selección de héroes/draft (salvo consulta directa), pantalla de pausa larga o marcador post-partida.
